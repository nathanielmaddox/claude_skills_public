# AI & Agents

Skills for building AI-powered features, agents, and managing LLMs in production.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| AI Agent Builder | `ai-agent-builder` | Agent architecture (ReAct, plan-and-execute, multi-agent), tool use, memory, RAG, guardrails |
| LLM Ops | `llm-ops` | Prompt management, monitoring, evaluation, cost optimization, fine-tuning |
| Prompt Engineer | `prompt-engineer` | SKILL.md content, agent prompts, context window management |
| Claude API | `claude-api` | Building apps with Claude API or Anthropic SDK |

## When to Use

- **ai-agent-builder** — Building chatbots, AI assistants, autonomous agents, agentic workflows
- **llm-ops** — Running LLMs in production, monitoring costs, A/B testing prompts
- **prompt-engineer** — Crafting skill prompts, optimizing agent behavior, context management
- **claude-api** — Using Claude API, Anthropic SDK, or Agent SDK in code

## Usage Examples

```
Skill({ skill: 'ai-agent-builder', args: 'Design a customer support agent' })
Skill({ skill: 'llm-ops', args: 'Set up prompt versioning and cost tracking' })
Skill({ skill: 'claude-api', args: 'Integrate Claude into the ERP for AI search' })
```
