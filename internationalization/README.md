# Internationalization

Skills for multi-language support and locale management.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| i18n Specialist | `i18n-specialist` | RTL support, CLDR, ICU MessageFormat 2.0, Intl APIs, locale management (W3C/Unicode) |

## When to Use

- Adding multi-language support to an app
- RTL layout issues
- Date/number/currency formatting for different locales
- Translation workflow setup

## Usage Examples

```
Skill({ skill: 'i18n-specialist', args: 'Add multi-language support to the ERP' })
```
