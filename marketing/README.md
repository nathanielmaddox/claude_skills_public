# Marketing

Skills for email marketing and automation.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| Email Marketing Strategist | `email-marketing-strategist` | Deliverability (SPF/DKIM/DMARC), automation sequences, segmentation, Resend/SendGrid, GDPR/CAN-SPAM |

## When to Use

- Email campaign design, drip sequences, newsletters
- Deliverability troubleshooting (SPF, DKIM, DMARC)
- Transactional vs marketing email architecture
- Email automation workflows (welcome, onboarding, win-back)

## Usage Examples

```
Skill({ skill: 'email-marketing-strategist', args: 'Design onboarding email sequence for new ERP users' })
```
