# Documentation

Skills for technical writing and documentation standards.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| Technical Writer | `technical-writer` | Enterprise docs, SOPs, runbooks, architecture docs (Diátaxis, docs-as-code), Mintlify/Fumadocs/Starlight/Docusaurus |

## When to Use

- Writing SOPs, runbooks, or architecture documentation
- Setting up a docs site (Mintlify, Fumadocs, Docusaurus)
- Improving existing documentation structure
- API documentation

## Otesse Context

- Docs site: `otesse_docs` at docs.otesse.com (port 3011)

## Usage Examples

```
Skill({ skill: 'technical-writer', args: 'Write API documentation for the booking endpoints' })
Skill({ skill: 'technical-writer', args: 'Create an architecture decision record for choosing Convex' })
Skill({ skill: 'technical-writer', args: 'Write an onboarding runbook for new developers' })
```
