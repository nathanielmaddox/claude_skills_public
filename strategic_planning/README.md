# Strategic & Planning

Skills for feature planning, product strategy, and project kickoff.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| Product Manager | `product-manager` | Feature breakdown, user stories, acceptance criteria, scope management |
| Project Inception | `project-inception` | Transforms vague ideas into structured project foundations |
| AI Product Strategist | `ai-product-strategist` | AI/LLM integration strategy based on OpenAI & Anthropic best practices |

## When to Use

- **product-manager** — Breaking down a feature into stories, writing acceptance criteria, managing scope
- **project-inception** — Starting a brand new project from a vague idea, need structured foundation
- **ai-product-strategist** — Deciding how to integrate AI/LLM features into a product

## Usage Examples

```
Skill({ skill: 'product-manager', args: 'Break down the booking flow feature' })
Skill({ skill: 'project-inception' })
Skill({ skill: 'ai-product-strategist', args: 'Add AI-powered search to the ERP' })
```
