# Design & UX

Skills for UI/UX design, accessibility, and visual design patterns.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| UI/UX Designer | `ui-ux-designer` | Design reviews, accessibility audits, UX improvements, component design |
| Copywriter | `copywriter` | Microcopy, error messages, CTAs, brand voice consistency |
| React Flow Designer | `react-flow-designer` | Node-based UIs, diagrams, flowcharts, workflow builders |
| Accessibility Auditor | `accessibility-auditor` | WCAG 2.2, ARIA patterns, screen reader testing, cognitive accessibility |
| Landing Page Designer | `landing-page-designer` | Conversion-optimized pages, hero sections, CTAs, Framer Motion |
| Dashboard Designer | `dashboard-designer` | SaaS admin panels, data viz, tables, filters, sidebar nav |
| Mobile UI Designer | `mobile-ui-designer` | Mobile-first responsive, touch interactions, iOS/Android patterns, PWA |
| Booking Flow Designer | `booking-flow-designer` | Service booking UX, quote generation, pricing transparency, multi-step forms |

## When to Use

- **ui-ux-designer** — General design review, improving an existing UI, component design decisions
- **copywriter** — Writing button labels, error messages, empty states, onboarding text
- **react-flow-designer** — Building node editors, workflow builders, org charts, dependency graphs
- **accessibility-auditor** — WCAG compliance check, screen reader testing, keyboard navigation audit
- **landing-page-designer** — Marketing pages, conversion optimization, hero sections
- **dashboard-designer** — Admin panels, data-heavy interfaces, filter/table layouts
- **mobile-ui-designer** — Mobile-first design, touch targets, bottom sheets, gestures
- **booking-flow-designer** — Booking forms, service selection, quote flows, checkout
